## Port changes

- `UIBuyBrowsePanel.BuildSubSortArt` — StrInd → member table (manifest-exact
  names; OrdinalIgnoreCase FAR lookup tolerates case drift).
- `UIBuyBrowsePanel.ResolveSubSortArt(cat, mode)` — **build plaques load the
  FULL image** via `UIOriginal.EnsureResolved(...).Get(...)`; buy sheets keep
  `Frame(member, 0)`. Reason (data-derived): `toolBtnTerrain` is 156×39 =
  exactly 4×39, and `Frame()` crops width==k×height (k=2..4) sheets into
  frames — it would silently mis-crop the Terrain plaque to 39×39. The build
  plaques are single-frame (text baked in; no other member's ratio is an
  integer 2..4). Used both in the button loop and InitSubcategory's main-button
  ReplaceImage.
- The R122 exclusion (`Mode != UICatalogMode.Build`) at the OriginalName
  resolution is replaced by a build branch that fills OriginalName from the
  table; captions/tooltips were ALREADY the generic `GetString(cat.StrTable,
  cat.StrInd)` = STR# 139 verbatim, and now ride original art with
  `OriginalStyle` chrome-skipping like buy mode.
